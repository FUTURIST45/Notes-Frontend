# Notes Frontend

React frontend for the Secure Personal Notes App.

## Stack

- React
- TypeScript
- Vite
- React Router

## Setup

Install dependencies:

```powershell
npm.cmd install
```

Optional environment file:

```powershell
Copy-Item .env.example .env
```

Default API URL:

```env
VITE_API_URL=http://localhost:4000/api
```

Run locally:

```powershell
npm.cmd run dev
```

Build:

```powershell
npm.cmd run build
```

Open the app at:

```text
http://localhost:5173
```
